Импорт биконов из Excel

Инструкция по формату файла

Excel файл должен содержать следующие колонки (первая строка - заголовки):

  • Обозн. в проекте (обязательно) - обозначение бикона
  • Шахта (обязательно) - название шахты, например "Нефтешахта №1"
  • MAC-адрес (обязательно) - MAC-адрес бикона
  • Зав. № (обязательно) - серийный номер
  • МИНОР (обязательно) - значение МИНОР
  • Дата монтажа (обязательно) - в формате ДД.ММ.ГГГГ или ДД/ММ/ГГГГ
  • Подсистема (опционально) - по умолчанию "Позиционирование"
  • Выработка (опционально) - название выработки
  • Уклонный блок (опционально) - название уклонного блока
  • Пикет (опционально)
  • Установлен (опционально) - "Да"/"Нет" или True/False, по умолчанию False
