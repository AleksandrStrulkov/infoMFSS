# SPEC-03: Рефакторинг UI страницы профиля и блока приглашений

## 1. Контекст и проблема
В рамках SPEC-02 был добавлен функционал выпуска инвайтов, но блок размещён на странице асимметрично, выбивается из сетки, использует разнородную типографику и выглядит чужеродной заплатой рядом с аккуратной центральной формой профиля.

## 2. Цель
Привести страницу профиля к единому современному визуальному стилю в рамках существующей дизайн-системы (Bootstrap):
- Либо единый монолитный блок с вкладками (Bootstrap Tabs: «Данные профиля» / «Приглашения»).
- Либо аккуратный стек карточек (Cards) одинаковой фиксированной/адаптивной ширины, отцентрированных по горизонтали.
- Исключить визуальный разнобой шрифтов, кнопок и отступов.

## 3. Требования к UI/UX
1. **Единый контейнер**:
 - Форма редактирования профиля и блок работы с инвайтами должны находиться внутри одной сетки (например, `col-lg-8 col-md-10 mx-auto`).
 - Если используется компонент с вкладками (`card-header-tabs`), обе секции живут внутри одной карточки.
 - Если используются две отдельные карточки, они должны иметь одинаковые классы оформления, одинаковую ширину и стандартный вертикальный отступ между собой (`mt-4`).
2. **Блок приглашений**:
 - Аккуратная кнопка генерации ссылки с иконкой и понятным текстом (например, «Создать приглашение»).
 - Инпут с готовой ссылкой должен поддерживать inline-копирование в буфер обмена (кнопка «Копировать» рядом с полем).
 - Список активных инвайтов оформлен компактной таблицей или аккуратным списком (`list-group list-group-flush`) с понятными бейджами статуса (активен / использован / истёк).
3. **Согласованность стилей**:
 - Использовать только существующие классы Bootstrap и темы проекта (без инлайн-стилей `style="..."`).
 - Заголовки, отступы (`mb-3`, `p-3` и т.д.) и кнопки (`btn btn-primary`, `btn-outline-secondary`) должны соответствовать остальным страницам проекта.
4. **Ограничения**:
 - Не ломать существующие формы Django, CSRF-токены, POST-эндпоинты выпуска ссылок и валидацию.
 - Не трогать бэкенд-логику `users/views.py` и сервисов, если в этом нет острой необходимости для рендеринга.
